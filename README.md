**DateTime Helper**

## Описание проекта

DateTime Helper — расширение для Visual Studio Code, предназначенное для быстрого добавления текущей даты и времени в открытый текстовый документ.

Плагин упрощает работу с текстом и позволяет вставлять дату и время без необходимости вводить их вручную.

## Возможности плагина

Расширение предоставляет три команды:

1. **DateTime Helper: Insert Date** — вставляет текущую дату в формате `дд.мм.гггг`.
2. **DateTime Helper: Insert Time** — вставляет текущее время в формате `чч:мм:сс`.
3. **DateTime Helper: Insert Date and Time** — вставляет текущую дату и время в формате `дд.мм.гггг чч:мм:сс`.

Все команды доступны через палитру команд Visual Studio Code (`Ctrl + Shift + P` или `Cmd + Shift + P`).

Если текстовый документ не открыт, плагин выводит предупреждение с просьбой открыть файл.

## Установка и запуск проекта

1. Склонировать репозиторий:

```bash
git clone [ССЫЛКА НА РЕПОЗИТОРИЙ]
```

2. Перейти в папку проекта:

```bash
cd datetime-helper
```

3. Установить зависимости:

```bash
npm install
```

4. Выполнить компиляцию:

```bash
npm run compile
```

5. Открыть проект в Visual Studio Code:

```bash
code .
```

6. Нажать F5 для запуска расширения в режиме отладки.

## Использование

1. Открыть текстовый файл в Visual Studio Code.
2. Установить курсор в место вставки.
3. Открыть палитру команд сочетанием `Ctrl + Shift + P` или `Cmd + Shift + P`.
4. Выбрать одну из команд DateTime Helper.
5. Текущая дата и/или время будут вставлены в позицию курсора.
